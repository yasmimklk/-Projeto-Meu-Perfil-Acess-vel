
# 👤 Meu Perfil Acessível

## Sobre o projeto

O projeto Meu Perfil Acessível foi desenvolvido utilizando HTML5 e CSS3.

O objetivo é apresentar o perfil fictício de um estudante de maneira clara, organizada e acessível.

A página apresenta informações pessoais fictícias, interesses, formas de aprendizagem e rotina diária.

O site foi desenvolvido pensando na facilidade de leitura e navegação em computadores e celulares.

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Conteúdo da página

- Perfil do estudante.
- Avatar ilustrativo.
- Informações pessoais fictícias.
- Meus gostos.
- Como eu aprendo melhor?
- Minha rotina.
- Botão de informações completas.

## Práticas de acessibilidade

- Textos curtos e objetivos.
- Títulos organizados.
- Fonte de fácil leitura.
- Bom contraste entre texto e fundo.
- Espaçamento adequado.
- Poucas cores.
- Informações divididas em seções.
- Imagem com descrição alternativa (alt).
- Links com nomes claros.
- HTML semântico.
- Layout responsivo para celulares.
- Navegação pelo teclado com foco visível.

## Reflexão

**Por que é importante conhecer as necessidades dos usuários antes de criar uma interface?**

É importante conhecer as necessidades dos usuários para criar uma página que seja fácil de utilizar e compreender.

Cada pessoa possui necessidades e formas diferentes de acessar as informações.

Uma interface organizada facilita a leitura e a navegação.

Também é importante utilizar textos claros, cores adequadas e elementos fáceis de identificar.

Dessa forma, mais pessoas conseguem utilizar o site com autonomia.

Conhecer os usuários ajuda a evitar dificuldades durante a navegação.

Assim, podemos desenvolver páginas mais acessíveis, inclusivas e agradáveis.
